# HCTG_Echoes-of-the-Cosmos

My project is game about space and it can be played on Itch.io. This is the demo link: https://aerobotx.itch.io/echoes-of-the-cosmos

You have been transported to the beginning of the solar system. Now you must go through the core of each planet in the solar system before you return home. Your mission: survive at all costs. Safe travels.

All of the art in this game was made by me and I used GDscript to code the game and character. This game isn't completely done, anyone could add aliens to fight the main character, a health bar that keeps up with the oxygen tanks, a more cool way of showing the character respawning when they fall, and a way to make it more interactive. Maybe add some plot twists along the way or some surprise scenes. 

I am trying to explore game development so I used AI to help me with the GDScript for the falling asteroids and shooting disks. Later, I created the falling ice shards once I figured out how the logic works since I am able to understand Python. Additionally, I used AI to figure out how to create zero gravity in the asteroid belt.
